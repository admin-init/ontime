# Demo 素材：到点 · 录屏用截图

本目录是「到点」Demo 录屏（3–5 分钟）用的输入素材。共 **三套**，分别扮演不同来源与不同用途：

- **A 套（自拟，未来日期）**——录屏**主流程**用。演示日 = **2026-11-08**，这套素材的时间全部落在演示日之后，
  行动台不会显示"逾期"。
- **B 套（真实，未来日期）**——演示"**联网核实找到官方原文**"用。真实公开页面（西南交通大学数学学院），
  截止 2026-11-10 17:00 仍在未来，材料清单完整。
- **C 套（真实，历史通知）**——演示"字段级溯源 / 不静默覆盖"用。真实公开页面（吉林大学党委学生工作部），
  但事件日期为 2026-10-26，**截止已过**，请勿用于主流程。

所有图片由 `generate.py` 用 Pillow 渲染，文字是真实排版的矢量文本（非模糊占位），
**字号在 1x 下不小于 15px**。

## 5. 拍摄时的使用顺序（建议）

**主流程（A 套，自拟，未来日期）**

1. `notice_future.png` —— 拖入"官网/通知"来源。系统抽出活动名称、时间、截止、地点、材料、提交方式，
   每个字段都带原文出处。
2. `chat_future.png` —— 拖入"聊天记录"来源。系统发现：
   - 地点出现**第二个值**（弘毅楼A座3楼报告厅）→ 与通知里的值**并列展示，不静默覆盖**，由用户确认；
   - 材料出现**新的一项**（一页项目介绍）→ 单独列出来源，不并入旧材料；
   - 截止时间只是群友的**疑问**，没有新值 → 保持原值，并显示"未找到明确适用的官方依据"。
3. `notice_future_2.png`（可选）—— 官方补充说明到达后，地点/材料/截止三个字段被官方口径确认或变更，
   用户确认后才更新，且更新可撤销。

**联网核实（B 套，真实）**

4. `notice_real_future.png` —— 用 B 套跑"联网核实"，检索到原文
   <https://maths.swjtu.edu.cn/info/1064/27964.htm>，逐字段比对；
   核实不到的字段（如收件邮箱）显示"未找到明确适用的官方依据"。

**溯源（C 套，真实历史通知）**

5. `notice.png` —— 单独用于演示"每个字段可回溯到原文片段"；
   因为截止时间已过（2026-10-26），**不要**用它做主流程的截止倒计时演示。

## 7. 关于"能被 Bing 搜到"的说明（未能证实，需主控复核）

- 本机 **Bing 中文版对多词中文查询严重降级**：查询"吉林大学 小米奖 评审答辩会""一站式学生社区 琢育计划"
  "西南交通大学 数学学院 助梦启航"等，均返回"吉林省"维基、知乎、AI 人设模板、PC Review 等无关结果，
  页面标注"内容使用 AI 生成"。因此**在本环境无法用 Bing 证明或证伪任何页面的索引状态**。
- 间接证据：同一轮排查中，Bing 对 `ynu.edu.cn`、`pku.edu.cn`、`sysu.edu.cn`、`shnu.edu.cn` 的
  "讲座/通知"页**能**返回结果，说明 Bing 对高校通知页有覆盖；360 搜索实测**能**命中
  `maths.swjtu.edu.cn` 与 `xsc.jlu.edu.cn` 的正文页。
- **建议**：录屏前用真实 Bing 账号再确认一次；核实步骤的检索词用"学校名 + 学院 + 标题关键词"的**短查询**
  （如 `西南交通大学 数学学院 助梦启航`），不要用整句标题，否则 Bing 中文版容易跑偏。

## 8. 脱敏与合规说明

- 真实通知素材（B/C 套）均为**白底正式通知**版式，页脚有"演示素材"小字，避免被误当作原始网页截图。
  流水线对照时可忽略 `.txt` 最后一行页脚。
- 原文中的**联系人姓名、办公电话、收件邮箱**均未出现在素材中；提交方式写作"收件邮箱见通知原文"，
  既保留语义又不泄露具体信箱。
- 群聊素材的人名（李同学/王同学）、群名、对话全部虚构；头像为纯色圆形加单字，
  无真实头像、手机号、学号、身份证号。
- A 套为完全自拟：`启澜大学` 是虚构学校，页脚与本文均明确标注"自拟"。
