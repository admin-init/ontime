# 能力表 · 与视频 Agent 对接

版本：v1｜2026-11-08｜维护：主控
用途：宣传片（105s）与流程片（≈4min）的分镜依据，以及片尾/配套说明的能力口径。
**开发范围不因本表扩大**：`入口`/`样例`/`规划` 三类不追加后台实现。

> **口径更新（v0.2 之后）**：本文写于第一阶段。此后官网同步 + 变更检测、`.eml/.mbox` 导入、IMAP 只读连接、自定义站点（`site:` 限定）、站点调研 Agent、站内提醒均已实现并实机验证；「二、入口」不再准确。
> 对外口径以 [`../README.md`](../README.md) 的能力清单与 `GET /api/capabilities` 为准（第三方 API 源仍为 `unverified`）。

## 状态定义

| 标记 | 含义 | 片中可以怎么用 |
|---|---|---|
| ✅ 真实 | 代码已完成，且由执行 Agent 实机验证过 | 可直接实拍，可展示真实结果与耗时 |
| 🟡 入口 | 界面或接口存在，后台未完成 | 可拍入口与空态，必须标注「演示暂未接入」 |
| 🔵 样例 | 允许用固定样例/预置数据展示 | 必须标注「样例数据」或「界面示意」，不得称为实时结果 |
| ⚪ 规划 | 产品方向，本轮未实现 | 概念动画/示意图，标注「规划」 |

## 一、真实实现（核心闭环，实拍为主）

| 能力 | 状态 | 证据 | 建议镜头 |
|---|---|---|---|
| 截图上传 / 电脑粘贴收录 | ✅ | `POST /api/ingest/screenshot`，视觉模型真实转录 | 全屏拖入 `notice_real_future.png`，粘贴板 `Ctrl+V` 特写 |
| 截图 → 结构化事件 | ✅ | 四步进度：识别截图 → 整理事项 → 查找关联事件 → 等待确认 | 进度条推进 + 结果卡出现的 3 秒特写 |
| 活动时间与报名截止分离 | ✅ | 事件字段 `start_at` 与任务 `due_at` 是不同实体 | 详情页并排展示两行，指一下两个日期 |
| 字段级来源 | ✅ | 每个字段带 `claims`：原文片段 + 来源缩略图 | 点开「提交截止」右侧来源点，弹出原文高亮 |

| 行动清单 / 勾选 | ✅ | `POST /api/tasks/{id}/toggle` | 行动台勾掉一项，计数变化 |
| 日历导出 | ✅ | `GET /api/events/{id}/ics` | 点导出，浏览器下载提示 |

## 五、两版片子的侧重

**105 秒宣传片**
- 0–40s：截图 → 结构化事件（实拍）
- 40–70s：第二份信息 → 冲突 → 用户裁决（实拍）
- 70–95s：联网核实 → 原文依据 / 未确认（实拍）
- 95–105s：官网、邮件入口各 1 个镜头 + 自定义查询概念 3 秒 + 片尾能力说明

**约 4 分钟流程片**
- 90% 篇幅给核心闭环，按操作顺序完整走一遍（可分段拍摄）
- 开场 10 秒交代"同一事件、多个来源"，结尾 20 秒展示其他入口与规划
- 不逐项执行未实现的后台服务
