## 决策记录

- 2026-11-08 技术栈 FastAPI + React + SQLite（用户已定，不迁移）。
- 模型 Key 存 `~/.ontime/llm_key`，不入库、不打印。DeepSeek `deepseek-flash` 支持图片输入。
- 检索用 360（so.com）为主、Bing 为备；实测本机 Bing 中文检索返回无关结果，360 能命中 edu.cn 正文页。失败时如实返回 not_found，不启用缓存冒充实时。
- 官网抓取 / IMAP / 推送：仅入口，`/api/capabilities` 标注 `entry`。
- 宣传口径：允许用入口、概念动画、样例展示完整产品方向，但必须标注「界面示意 / 概念演示 / 规划」，不得伪造已连接、同步成功、实时抓取。片尾集中声明完成范围。
- 自定义网站查询：仅写入产品说明（`docs/能力表_与视频对接.md`），本轮不开发浏览器 Agent、凭证托管、脚本沙箱。设置页有余力时加只读配置入口。
- 录制时间：素材截止 11-10；若延后录制，改用自拟未来素材 `notice_future.png`，不引入假时钟。
- 合并采用「Claim 改指向」，可撤销；冲突保留候选由用户裁决。

## 风险

- 视觉模型对聊天截图的转录质量 → 素材 Agent 保证字号与清晰度。
- 真实检索可能找不到演示事件的原文 → 验收时若 not_found，保留「未确认」这条真实路径，并用另一条真实通知补拍「找到依据」。
- 前端与后端并行 → 契约字段为准，集成期由 T4 统一修正。
